# 客运抽样扩推台

城际客运统计员把问询回收与班次出票表相联，按票号复核重访，按当前分层扩推各问项人数。入口默认展示「重访与改层」样例。

## 运行

`docker compose up --build` 后访问 `http://localhost:18473`。本机可安装 `requirements.txt`，执行 `python -m app.main`。归档数据库由 `SURVEY_ARCHIVE` 指定，默认 `var/survey.db`。停止服务后移除该数据库或 Compose 命名卷可重新试跑。

## 复核路线

1. 在首页查看有效矩阵、样本阶梯和偏差横条，核对 290 人 = 250 人扩推 + 40 人不可推断；同页「公开范围裁定」给出各分层能否公开。
2. 到班次与分层校验查票号 `00011` 改入枢纽，到非响应权重校准查基础权 3、校准后 50。
3. 在扩推整数分配切换城北与枢纽，查看余数及补 1 的类别。
4. 打开批次留档复跑，归档并复算。进入样本证据签发，下载公开签发件 JSON（含公开裁定与印章，不含原始答卷）。
5. 切换「晚到回访与单答卷层」样例，查看单答卷层（末班）仅留线路参考、选项明细被抑制；晚到回访使该层变为多答卷后公开范围重算。

## 公开裁定规则

- 全市各选项扩推人数照原数公开，供调度直接使用。
- 仅抑制**单答卷层**（层内只有一份有效答卷）的选项明细：全市数减其余分层即可反推该份答案。抑制层保留层名、出票人口、有效份数与状态作为线路参考，隐去各选项人数、配额、校准与观测明细。
- 零响应层与多答卷层一律公开；不额外抑制其他层，以免损失线路参考。
- 签发页与下载件由同一 `build_publication` 生成、同一印章留档；公开包不含原始答卷，原件只存内部归档供复核。
- 晚到回访改变公开范围时按新原件重算并生成新批次；已发版本印章自包含、仍可核验，重跑同批不重复签发。

`GET /api/survey/<stage>` 执行样例阶段，阶段名见 [DEPTH](docs/DEPTH.md)（含 `disclosure`）。向同一路径 POST `{"tables":{"returns":"...","frame":"..."}}` 可复核自己的 CSV。`POST /api/runs` 提交同样的 `tables` 或 `{"sample":"dirty"}`（另有 `clean`、`late`）。`GET /api/runs/<id>` 查档（含 `disclosure` 与 `issuance`），`POST /api/runs/<id>/rerun` 复算，`GET /api/export/<id>` 领取公开签发件（重复领取同批不重复签发）。

字段和计算规则详见 [数据字典](docs/DATA-DICTIONARY.md)。本机测试执行 `python -m pytest -q`。
